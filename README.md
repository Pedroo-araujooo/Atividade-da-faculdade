# Atividade-da-faculdade
Verificador de Aprovação de Aluno

Algoritmo que verifica se um aluno foi aprovado ou reprovado com base na média das notas.

A atividade da faculdade pedia a implementação em Python. Desenvolvi a lógica original em JavaScript (linguagem que domino) e depois converti para Python com apoio de IA, já que ainda estou aprendendo essa linguagem.

Arquivos:

NotasEmjs.js — versão original, feita por mim
NotasEmPy.py — versão convertida para Python, entregue como atividade

Tecnologias: JavaScript, Python
